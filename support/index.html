Frequently Asked Questions

How do I add a new project workspace?

Click the “Add Project” button in the sidebar or drag and drop any project directory into the window. Vird Launcher Hub automatically inspects package.json, Makefiles, Python scripts, or Docker compose files to detect available run commands.

How does the Docker integration for n8n work?

If Docker Desktop is running on your Mac, Vird Launcher Hub can pull and start the official n8n Docker image with persistent local volume storage. Alternatively, if you have n8n installed via npm or Homebrew, it can run directly as a native node process.

How does Port Inspection prevent address collisions?

Before or during execution, Vird Launcher Hub inspects local socket bindings. If port 3000, 8080, or 5678 is already held by a lingering daemon, the app highlights the owning PID so you can terminate the dangling process with one click before starting your server.

How are Git credentials and GitHub authentication stored?

Git credentials use standard macOS Keychain integration or your local Git credential helper. Personal access tokens are stored securely in your private application storage and are never sent to any third-party server.

Why does macOS ask for permission to access project folders?

In compliance with Apple App Store Sandbox security requirements, macOS asks you to confirm access when you select a project directory with the native file picker. This ensures the app only has access to directories you explicitly choose.
