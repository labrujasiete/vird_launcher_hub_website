Privacy Policy

Last updated: October 27, 2026

Our Core Privacy Principle: 100% Local Execution

Vird Launcher Hub is engineered with a strict local-first philosophy. We do not collect, transmit, sell, or analyze your source code, your environment variables, your terminal logs, or any personal identifiers. Everything stays entirely on your own Mac.

1. Information We Do Not Collect

Unlike many developer tools, Vird Launcher Hub does not incorporate telemetry, product analytics, advertising identifiers, or user tracking SDKs. We do not collect:

  • Your source code, file contents, or repository names.
  • Environment variables, secret keys, or authentication tokens.
  • Terminal command logs, process outputs, or runtime statistics.
  • IP addresses, hardware UUIDs, or device location data.
  • Personal details such as your name, email, or physical address.

2. Apple App Sandbox & Local Permissions

Vird Launcher Hub runs within the strict boundaries of the macOS App Sandbox (com.apple.security.app-sandbox) as mandated by Apple for Mac App Store applications.

User-Selected Files

The application only accesses project directories that you explicitly select using the macOS open panel. Access rights are persisted using Apple security-scoped bookmarks.

Local Network Connections

Network access is restricted to localhost (127.0.0.1) port inspection and direct Git remotes you specify. No third-party network calls are made.

3. Git & GitHub Credentials

If you connect GitHub or enter personal access tokens, credentials are handled through standard local Git credential storage or your private application settings. They are used solely to authenticate your Git push and pull operations directly against your Git server and are never shared with any intermediary service.

4. Third-Party Services & Dependencies

Vird Launcher Hub communicates directly with local tools installed on your system (such as Node.js, Docker, Python, or Git). It does not embed third-party advertising, analytics, or behavioral profiling services.

5. Children's Privacy

Because Vird Launcher Hub does not collect personal data from any user, we do not knowingly collect or solicit information from children under the age of 13.

6. Updates to this Policy

If we make any modifications to our privacy practices in future updates, we will update the “Last updated” timestamp at the top of this document and publish the revised notice at this URL.
